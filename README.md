# 🚀 SolnHub - Modern Marketing Agency Landing Page

A modern, responsive marketing agency landing page built with **React + Vite**.  
The project is designed to showcase services, portfolio, and contact sections with a clean UI/UX experience.

---

## ✨ Features

- ⚡ Fast performance using Vite
- 📱 Fully responsive design (mobile-first)
- 🎨 Modern UI/UX design
- 🧭 React Router navigation
- 📩 Contact form (Formik)
- 🎯 Smooth scrolling sections
- 🧩 Reusable components

---

## 🛠️ Tech Stack

- React.js
- Vite
- React Router DOM
- Formik
- React Icons
- CSS / Custom Styling
